# Portofolio Muhammad Rayyan Nafis

Website portofolio statis berbasis HTML, CSS, dan JavaScript (tanpa framework).

## Struktur
- `index.html` : halaman utama (HTML + CSS + JS dalam satu file)
- `foto-profil.jpg` : foto profil
- `vercel.json` : pengaturan deploy Vercel

## Jalankan lokal
Buka `index.html` di browser, atau jalankan server sederhana:

    npx serve .

## Deploy ke Vercel
1. Upload folder ini ke repo GitHub.
2. Buka vercel.com, login dengan GitHub, klik **Add New > Project**.
3. Pilih repo ini, lalu klik **Deploy**. Framework Preset: **Other**, kosongkan Build Command dan Output Directory.
